# 使い方（QMK 版のキー操作・Bluetooth・電源）

このリポジトリの QMK を書き込んだ後の操作です。純正 FW の操作をできるだけ再現しています。VIA 対応版で変更できる内容は [via.md](via.md) を参照してください。

## キー配置（default keymap）

- **Base レイヤー**：US 配列の HHKB 標準配置です。右下の `Fn` キーを押している間、Fn レイヤーになります。
- **Fn レイヤー**：

| 行 | Fn と同時に押すキー → 入力 |
|---|---|
| 数字の行 | `Esc`→Esc、`1`〜`=`→F1〜F12、`\`→Insert、`` ` ``→Delete |
| Tab の行 | `Tab`→Caps Lock、`I`→Print Screen、`O`→Scroll Lock、`P`→Pause、`[`→↑、`Backspace`→Backspace |
| Control の行 | `A`→音量−、`S`→音量＋、`D`→ミュート、`H`→テンキー `*`、`J`→テンキー `/`、`K`→Home、`L`→Page Up、`;`→←、`'`→→、`Enter`→テンキー Enter |
| Shift の行 | `N`→テンキー `+`、`M`→テンキー `-`、`,`→End、`.`→Page Down、`/`→↓ |

- VIA 対応版の初期配置も同じです（VIA で変更できます）。
- キーボード背面の DIP スイッチのうち、QMK が参照するのは **SW6（自動スリープの無効化）だけ**です。SW1〜SW5（純正のキー配列モードなど）は無視され、配置は上の表で固定です。

## 出力先（USB / Bluetooth）

- **自動**（既定）：USB でホストにつながっていれば USB、そうでなければ（電池駆動、充電器のみ）Bluetooth に出力します。
- `Fn`+`Ctrl`+`1`〜`4` で Bluetooth のスロットを選ぶと、USB 接続中でも Bluetooth に出力します。
- スロットを切り替えるときは、切り替える前のホストに押していたキーの解放を送ってから接続先を変えます（[reverse-engineering/bluetooth-protocol.md](reverse-engineering/bluetooth-protocol.md) §11）。
- `Fn`+`Ctrl`+`0` で自動に戻します（青 LED が 1 秒点灯）。
- 電源を入れたとき（電池駆動）は、最後に使ったスロットに再接続します。未登録のスロットでは自動ではペアリングを始めません（`Fn`+`Q` から登録します）。

## Bluetooth の操作

| 操作 | 動作 |
|---|---|
| `Fn`+`Ctrl`+`1`〜`4` | 登録済みのスロット 1〜4 に切り替える（青 LED がスロット番号の回数点滅） |
| `Fn`+`Q` | ペアリングモードに入る（青 LED が約 2.5 回/秒で点滅） |
| ペアリングモード中に `Fn`+`Ctrl`+`1`〜`4` | そのスロットに新しいホストを登録する（青 LED が約 5 回/秒で点滅。ホスト側で HHKB を選び、パスキーを求められたらキーボードで入力） |
| ペアリングモード中に `Fn`+`X` | ペアリングを取り消し、直前のスロットに再接続する |
| ペアリングモード中に `Fn`+`Ctrl`+`Delete`（Tab の行の右端、Backspace/Delete 刻印のキー）を押したまま `1`〜`4` | そのスロットの登録を削除する |

- ペアリングモードは 60 秒で自動的に取り消されます。
- **再接続の打ち切り（純正 FW と同じ）**：接続先が見つからないとき、または接続が切れたときは、青 LED を点灯して約 60 秒再接続します。失敗すると nRF（Bluetooth モジュール）を待機にして LED を消します。
  - 電池駆動かつ DIP SW6 が OFF：電源 OFF（自動スリープと同じ STOP）
  - DIP SW6 が ON、または USB 給電中：電源は切らず起き続けます。キーを押すか、電源ボタンの短押し（0.1〜2 秒）で再接続をやり直します
- Bluetooth ではマウスキー・NKRO・電源/スリープのシステムキーは送れません。メディアキーは純正の Bluetooth ファームが対応するものだけです。
- VIA 対応版では、これらの操作を好きなキーに割り当てたり、純正互換の組み合わせを無効にしたりできます（[via.md](via.md)）。
- ファームを書き込んだ後にペアリング情報が残るかは保証していません（書き込み後に再ペアリングせず Bluetooth で入力できた例はあります）。つながらない場合は `Fn`+`Q` から登録し直してください。

## 電源と自動スリープ（電池駆動時）

| 操作・状態 | 動作 |
|---|---|
| 電源ボタンを 2 秒長押し | 電源 OFF（オレンジ LED が点灯してから消灯） |
| 電源ボタンの短押し（0.1〜2 秒、電池駆動） | 接続中ならスロット番号の回数だけ青点滅。Bluetooth の再接続を諦めたあとなら再接続をやり直す |
| OFF 中に電源ボタンを 1〜10 秒押して離す | 起動する |
| OFF 中に USB を接続 | 起動する |
| 無操作が続く | 自動スリープ（既定 30 分。VIA 対応版は VIA で変更可）。復帰は電源ボタンか USB 接続 |
| DIP SW6 を ON | 自動スリープしない。Bluetooth 再接続に失敗しても電源は切らず、キーまたは電源ボタン短押しで再接続する |
| USB 給電中 | 電源ボタンと自動スリープは無効 |

- スリープ中はキーを押しても起きません（純正 FW と同じ）。
- 電池残量は純正と同じ 4 段階（100/15/5/0 %）で Bluetooth のホストに通知します。OS のバッテリー表示などで確認してください。キーボードの LED では表示しません。

### 電池駆動時の省電力動作

電池駆動中（USB 給電なし）は、電池を長持ちさせるため次のように動きます。USB 給電中は従来どおりです。

- MCU を 4 MHz で動かし（USB 給電中は 32 MHz）、USB 回路を止めます。純正 FW も電池駆動時は 4 MHz です。
- キーの走査は 5 ms ごとに 1 回で、その間は MCU を休ませます（純正 FW は約 11 ms ごと）。
- 走査の間は、キーの読み取り回路（OpAmp と ADC）を止めます。
- 起動（電源 ON）から約 1 秒間と、USB の抜き差しの直後（約 50 ms）は、切り替えずに 32 MHz のまま動きます。電池駆動中に USB を接続すると、32 MHz に戻して USB を起動し直します。

この動作に問題（キーの取りこぼしや誤入力、Bluetooth が切れるなど）があるときは、`-e HHKB_LOW_POWER=no` を付けてビルドしたファームを書き込むと、従来の動作に戻ります（[build.md](build.md#ビルドオプション)）。

**電池持ちの比べ方**（電流計なしでできる方法）：新品の電池に入れ替えた日時を記録し、Bluetooth のホスト（OS のバッテリー表示など）で残量が 100 % から 15 % に下がるまで、または入力できなくなるまでの日数を比べます。比べるときは、電池の銘柄、DIP スイッチ、接続する機器の台数、1 日に使う時間をそろえてください。純正 FW で同じ記録があれば、それと比べられます。

## LED

| 表示 | 意味 |
|---|---|
| 青が点灯したまま | Bluetooth に再接続中、または接続先の切り替え中（約 60 秒で消灯。失敗後は上の「再接続の打ち切り」） |
| 青が点滅（約 2.5 回/秒） | ペアリングモード |
| 青が点滅（約 5 回/秒） | 登録待ち |
| 青がスロット番号の回数点滅 | スロットを切り替えた、または電源ボタン短押しで接続スロットを表示した |
| 青が 1 秒点灯 | 出力を自動（USB 優先）に戻した |
| オレンジ | 電源 OFF の操作中 |

純正 FW の LED の詳細な解析は [reverse-engineering/led-indication.md](reverse-engineering/led-indication.md) にあります。

## JIS 配列の OS で使う

OS の配列設定を JIS のまま、US 刻印どおりに記号を入力する補正機能があります。`Ctrl`+`Alt`+`Shift`+`J` で ON/OFF を切り替えます。詳細は [jis-us-toggle.md](jis-us-toggle.md)。

## 書き込み用のモード（更新モード）に入る

- **bootmagic**：電源を OFF にした状態（または電池を外した状態）で、`Esc` を押したまま USB を接続します。数秒押し続けてから離してください。QMK の設定を初期化したうえで更新モードに入り、キー入力は効かなくなります。`python3 tools/flash.py --list` で `HHKB-Hybrid` と表示されれば入っています。
  - 電池駆動で電源が入ったまま USB を挿しても再起動しないため、bootmagic は働きません。先に電源ボタンを 2 秒長押しして OFF にしてください。
- 通常の書き込みでは bootmagic は不要です。`tools/flash.py` が自動で更新モードへ切り替えます。
