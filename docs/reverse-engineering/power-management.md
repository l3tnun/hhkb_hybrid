# 純正 FW の電源管理 (電源ボタン・スリープ) 解析

- 作成: 2026-09-13 (静的解析)
- 対象: 純正 A0.48 STM32 アプリ (`hhkb_stock_128k.bin` 0x08010000〜)。静的解析のみ
- 中間生成物: `build/b4/power/` (Git 管理外)
- [C] = コードで確認、[I] = 推定

## 1. 全体像

- ラッチ/レギュレータ制御ピンは無い [I 高]。「電源オフ」と「無操作スリープ」は同じ状態 (状態 0)
- 状態 0 では nRF を待機 (`40` → 03 に `10 00`、`83 01` を最大 3 秒待つ) にし、マトリクス/アナログ出力を Low にして、MCU を **STOP** (PWR_CR LPSDSR=1, PDDS=0, SLEEPDEEP, WFI;) [C]
- 起床要因は **EXTI5 (PC5 = 電源ボタン)** と **EXTI13 (PC13 = USB 給電)** の**立ち下がりのみ** (HAL mode 0x10210000) [C]。キーでは起きない。RTC/LPTIM/IWDG は使っていない [C]
- USB 給電中は STOP に入らない (ビジーループで SPI を処理)、USB サスペンドでも寝ない [C]

## 2. 電源ボタン (PC5)

| 状況 | 操作 | 動作 | 根拠 |
|---|---|---|---|
| 動作中 | 短押し (0.1〜2 秒) | 状態 3 (接続中) なら接続スロット番号の回数 LED0 点滅 [I]、状態 5 なら再接続 |〜 [C] |
| 動作中 | 2 秒長押し | 状態 0 (オフ)。USB 給電中も同じ | ほか [C] |
| オフ (STOP) | 1 秒以上押して 10 秒未満で離す | 起床: PC14 High、電池チェック、LED0 消灯、BT 再接続 (状態 4) または USB (0x3C) | [C] |
| オフ | 1 秒未満 | STOP に戻る | [C] |
| オフ | 10 秒以上 | LED1 を 3 秒点灯して、オフのまま | [C] |

オフへの手順: LED0 消灯/LED1 点灯 → nRF 待機 → (電池時) USB 停止 (USB_CNTR=0, D+ プルアップ解除) → `83 01` 待ち (3 秒) → LED1 消灯 → ボタンを離すまで待つ → PB0〜2, PB10〜15, PC6, PC7, PC8, PC14 を Low → STOP ループ。

起床時: PC13 でクロック選択 (電池 4MHz / USB HSI48+CRS) → ADC・タイマー・SPI1・NVIC (SPI1, EXTI4_15)・USB を再初期化。

## 3. 無操作スリープ

- カウンタ `0x2000009C` (秒)。状態 3/5 で、VBUS 無し かつ DIP SW6 相当 (`0x20000086[5]` = PC4 Low) が OFF のときだけ進む。キー押下でリセット [C]
- 上限 = `0x20000079` × 60 秒 → 状態 0。設定値は **EEPROM `0x08080520`** (1〜60 分、0 または 60 超なら 30 を保存) [C]
- その他のタイムアウト: ペアリング待ち 600 秒、状態 2 600 秒、再接続 60 秒 → 状態 0 (VBUS/SW6 なら状態 5) [C]
- DIP SW6 (PC4) ON: STOP せず状態 5 でキー走査を続け、キーで再接続 [C]。SW6 = 「キーで起床」[I 中高]
- QMK は再接続 60 秒の打ち切りと、SW6 ON 時の状態 5 相当（nRF 待機・LED 消灯・キー/電源短押しで再試行）を実装する。全スロット未登録時の自動 `01 00` は真似しない。仕様は [../usage.md](../usage.md)

## 4. 電池残量低下

- PB9 Low (0%) で電池時 LED1 点灯。2 秒長押しまたは 180 秒で: nRF 待機・出力オフ → **EXTI5 を無効化** (ボタンでは起きない) → STOP → USB 挿入でのみ起床 → リセット [C]

## 5. USB 給電の抜き差し

- STOP 中の USB 挿入: PC13 で起床、状態 0x3C (USB) [C]
- 動作中の抜去: 状態 3/5 (USB クロック) ならシステムリセット、0x3D なら状態 0。STOP 中の抜去では起きない [C]

## 6. QMK での注意点 (推定)

- **IWDG**: QMK は起動直後に IWDG (約 7 秒) を開始しており、STM32L0 の IWDG は STOP 中も止まらない。期限切れのリセットは `__early_init` のフェイルセーフで**更新モード**に入る → STOP 中も LSI 起動の LPTIM1 (EXTI29) で約 2 秒ごとに起きて IWDG を更新する必要がある
- `stm32_clock_init()` は RCC APB1ENR / PWR_CR / CCIPR / SYSCFG_CFGR3 を上書きする → STOP から復帰して再開するより、**起床 = ソフトウェアリセット**が単純 (純正のリセット経路と同様)。代償: ブートローダーが PD2 を High にするので nRF がリセットされ、再接続まで約 10 秒
- STOP 中は TIM21 (ChibiOS の時刻) が止まる。EXTI の保留 (ボタンのバウンス) はクリアしてから入る
- リーク対策: PC14/PC7/PC8 を Low、PB6 は High、USB の D+ プルアップと HSI48/VREFINT を止める
- STOP 中は SPI に応答できない → 事前に nRF を待機にする (応答の無い問い合わせを nRF が最大 600 回再試行するため)
- スリープ状態は保持しない (電源の入れ直し = 通常起動) ので、電池の抜き差しで必ず復帰できる
