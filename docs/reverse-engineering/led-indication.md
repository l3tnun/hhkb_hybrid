# 純正 FW の LED 表示パターン解析

- 作成: 2026-09-13
- 対象: 純正 A0.48 STM32 アプリ。静的解析のみ。中間生成物: `build/b4/led/`
- LED0 = PA8 = **青** (動作・接続の状態)、LED1 = PA9 = **オレンジ** (オフ・低電池の警告)。実機確認 2026-09-13 (二色 LED、外から1つ見える)。いずれも High で点灯。**ハードウェア上 LED1 が優先**され、LED1 点灯中は LED0 の論理状態を保持して LED1 を表示、LED1 消灯で LED0 が復帰する ()
- タイマー基準: TIM21 更新割込み が各カウンタを 1ms 刻みで加算 (電池時 PSC=99/ARR=40 → 1.023kHz、USB 時 ARR=160)。しきい値は `>` 比較 (0x63=100ms, 0x3E7=1000ms, 0x2710=10s, 0xEA60=60s)。無操作カウンタ `0x2000009C` は秒
- 状態変数 `0x20000044`: 0=オフ、0x3C=USB待機、0x3D=USB入力中、1=ペアリング、2=登録待ち、3=BT接続、4=再接続、5=待機(起きたまま)

## 状態ごとのパターン (すべて [C] コード確認)

| 状況 | LED0 (PA8) | LED1 (PA9) |
|---|---|---|
| オフ中にボタン長押し | 1 秒経過で点灯、離すまで点灯 | – |
| 1〜10 秒で離して起動 | 接続確立まで点灯、接続 (状態3) で消灯 | – |
| 10 秒以上長押し | 10 秒で消灯 | 3 秒点灯後に消灯 (起動しない) |
| リセット/電池挿入で起動 (登録あり) | 点灯 (状態4、1 秒ごとに再点灯) | – |
| USB 起動・登録なし (状態0x3C) | 最大 60 秒点灯 | – |
| 電池起動・登録なし | 消灯 | 3 秒点灯 → STOP |
| BT 再接続中 (状態4) | 点灯 | 消灯 |
| BT 接続 (状態3) | 消灯 | – |
| USB 待機 (0x3C) | 入って 60 秒点灯 → 消灯 | – |
| USB 入力中 (0x3D) | 入力時に 1 秒点灯 | – |
| ペアリング (Fn+Q、状態1) | 200ms 点灯/200ms 消灯 (2.5Hz) を、成立か 600 秒まで | – |
| 登録待ち (Fn+Ctrl+n、状態2) | 100ms 点灯/100ms 消灯 (5Hz) を、成立か 600 秒まで | – |
| ペアリング成立 | 点滅停止・消灯 (状態3へ) | – |
| ペアリング取り消し (Fn+X) | 点灯 (状態4) | – |
| 接続先切替 (Fn+Ctrl+1〜4) | 切替中は点灯 → 成立で消灯 | – |
| 短押し (0.1〜2秒、接続中) | (スロット番号+1) 回点滅 (200ms 点灯/800ms 消灯、周期 1 秒) → 消灯 | – |
| オフ (2秒長押し/無操作/タイムアウト、状態0) | 即消灯 | 3 秒点灯 (nRF `83 01` 待ち、最大 3 秒) → 消灯 |
| 無操作スリープ | オフと同じ | オフと同じ |
| 電池 15% (level1、電池のみ) | – | 変化時 600ms×1、以後約 17.6 秒→約 34.1 秒間隔 |
| 電池 5%/0% (level2/3) | – | 600ms×2 を約 17.6 秒間隔 |
| 電池 0% (電池のみ) | 消灯 | 停止 (180秒/2秒長押し) か USB 挿入まで点灯 |
| USB 給電中 | 電池点滅は抑制 (`0x200000ED`) | 消灯 |
| 登録削除 (`85`) | 表示なし | – |
| 充電 | LED コード無し (充電回路なし) | – |

## 優先順位

- ピン上は LED1 > LED0。低電池・オフ表示 (LED1) が LED0 のパターンを覆い隠し、LED1 消灯で LED0 が自動復帰
- 状態遷移のたびに LED を初期化 (`0x20000010 != 0x20000044`) するので、状態が変わると短押しのスロット点滅などは取り消される
